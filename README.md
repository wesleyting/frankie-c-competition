# Frankie C Brownie Naming Competition

A responsive campaign site for Frankie C's US$10,000 All-In Brownie naming competition.

The project supported the campaign from launch and entry collection through its post-campaign results and winner updates. Entries were collected through an embedded Jotform, while the Next.js site handled the campaign experience, official rules, privacy information, accessibility content, and responsive presentation.

## Project context

Frankie invited his audience to name the brownie. The US$10,000 prize was split among the entrants who submitted the selected name.

The default branch reflects the post-campaign version of the site. The original launch experience remains available in the repository history.

## Features

- Responsive campaign and results pages
- Embedded Jotform entry collection
- Official rules and privacy pages
- Accessibility information and cookie consent
- Post-campaign winner updates
- Vercel Analytics integration

## Stack

- Next.js 15
- React 19
- Tailwind CSS
- Jotform
- Vercel Analytics

## Local development

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
